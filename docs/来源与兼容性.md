## 安卓设备、声音与无线连接

- [scrcpy 4.1 音频说明](https://github.com/Genymobile/scrcpy/blob/v4.1/doc/audio.md)：系统声音采集要求 Android 11+；Android 11 启动采集时需要解锁。Android 10 及更早版本在当前方案下只提供视频，不以麦克风录音替代。
- [Android 官方 ADB 说明](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi)：Android 11+ 支持无线调试配对；旧版使用先 USB 授权再开启 TCP 调试的流程。家庭端分别登记配对端口和连接端口，并核对原设备身份。
- 传统 TCP 调试只用于可信家庭局域网，不将 ADB 端口映射到公网。iPhone 的外网连接经家庭服务端认证的 P2P 会话完成，平台不转发画面、音频或触点。
- 实体熄屏目前默认关闭。已测设备两次未能自动恢复亮屏，系统返回电源模式成功不能代替肉眼确认；无线连接不依赖熄屏功能。
- 应用登录、验证码、密码、支付验证及受保护画面依赖具体 App 与系统。通用远控和包名许可不代表所有中国生活或支付应用已适配，更不代表可以绕过这些验证。
- 已测无线视频、Core 打开系统设置以及 iPhone 系统画中画的证据见验收记录；不将模拟器音频验证写成旧版安卓真机支持音频。

## iOS 画中画与后台

实现使用 `AVPictureInPictureController`、`AVSampleBufferDisplayLayer` 和真实 WebRTC 视频帧。可参考 Apple 的 [画中画说明](https://developer.apple.com/documentation/avkit/adopting-picture-in-picture-in-a-standard-player)及 [Sample Buffer 内容源](https://developer.apple.com/documentation/avkit/avpictureinpicturecontroller/contentsource-swift.class/init%28samplebufferdisplaylayer%3Aplaybackdelegate%3A%29)。系统画中画、应用内小窗和全屏复用同一视频会话；没有视频通话或静音音轨保活。

画中画只读，人工操作需回到全屏；进入小窗或后台释放本人持有的输入权。已有视频且观看未关闭时，切后台会尝试启动画中画；未能启动或保持时暂停观看，关闭画面不取消服务器任务。普通同步、文件续传和 APNs 仍遵循各自的生命周期，不因增加视频后台模式就变成任意常驻服务。背景约束参考 [Apple 后台策略](https://developer.apple.com/documentation/backgroundtasks/choosing-background-strategies-for-your-app)。

## 当前连接与客户端差异

- 普通家庭 API 已支持可选端到端加密备用通道，使用固定 PyHPKE 依赖与 iOS CryptoKit。严格直连与允许备用通道是两种配置，不能再把整个项目写成“平台从不转发数据”；平台可转发密文并观察连接元数据。
- 安卓实时视频、系统声音和原始触点仍是独立 P2P 通道。普通 API 的备用路径不自动解决媒体打洞失败。
- iOS 会话重验支持同响应内的已鉴权快照。旧客户端仍可能先清空再重拉，新服务不自动升级旧 App。
- 自动审核是当前签名设备的可撤销委托，默认关闭；它不替代 HealthKit、位置、相机等系统权限。
- 当前 HealthKit 采集支持 README 列出的 14 类常用指标；样本量、系统权限、设备是否实际记录决定可用性，不承诺全部健康类型。
- 语音转写、TTS、APNs 来电与通话音频分别依赖对应组件。语音播放通过不等于主动来电和持续双向通话都已在目标环境通过。

本页上游链接用于说明来源；实际版本以仓库锁定文件、Manifest 和安装校验为准。外部服务限制和应用行为可能变化，部署者应在自己的环境重新验证。
