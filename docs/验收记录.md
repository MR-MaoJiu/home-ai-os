## 最近修复的验证范围

### 会话闪空与连接状态

问题：资料或记忆更新提高会话授权版本，旧客户端收到 reset 后清空页面再拉历史；状态流短暂结束又被立即标为整体离线，放大重载。

修复：服务端 reset 同时携带已重新鉴权快照；客户端原子替换，旧协议降级保留消息位置并遮蔽待核验正文。状态流断开先检查家庭 API，迟到失败不得覆盖新连接或其他请求已证实的在线状态。

证据：服务端会话、撤权、游标与并发事件回归 55 项通过；真机相关回归 51 项通过，环境依赖项单独跳过。真实手机连续三次只读重验均返回非空快照，没有额外历史请求。测试未修改聊天或配对。

对应：`test_conversations.py`、`ChatRefreshTests.swift`、`DirectTests.swift`。

### 健康资料已提供后反复索取

问题：复用仅匹配十五分钟内完全相同指标与时间，跨任务缺少已有资料目录；明确追问可能只有旧口头答复而没有统计。

修复：按实际范围投影已有账本，优先较新完整采集，仅补缺指标；合并新旧资料时重新核验版本。已查询却无样本的回执继续保留，不能用零值补齐或循环申请。明确重采仍实际采集。

证据：先在隔离用例复现子集和秒级范围漂移造成重复卡片；健康复用专项 63 项、规划与上下文专项 62 项、最终整合 52 项分别通过（有重叠，不累加）。对实际待办做了带审计的缩减修复，复用已有记录，保留原任务、原到期与设置；修复过程未调用模型或公开健康值。

对应：`test_health_reuse.py`、`test_health_history_context.py`。

### 自动审核

默认关闭，开启必须确认；只处理当前设备本人任务。工具、披露与指定资料走原审批逻辑，采集仍受系统权限约束；硬性禁止、其他成员批准、密码与缺少的信息不被代替。

证据：专项 26 项通过，另有真实 PostgreSQL/RLS 与并发关闭 2 项通过。真机状态、确认意图与窄屏样式测试通过；真实设备默认关闭的检查只读执行。迁移 `0033` 未替现有设备开启功能。

对应：`test_auto_review.py`、`test_auto_review_postgres.py`、`AutomaticReviewTests.swift`。

### 所有 AI 文字消息的朗读

接话、结果、等待、失败和仅富文本的答案统一生成朗读描述。来源校验不再依赖“任务必须成功”，而由 `chat-speech` 返回当前可访问投影。原始附件不因标题朗读被隐式下载。

证据：服务端投影与权限回归 41 项通过；iOS 相关回归 53 项通过，真实接口只输出消息类型和数量，公开短句完成真实播放与缓存重播。资料变化后暂停并重新校验，不能从旧音频复活撤权内容。

对应：`test_chat_speech_access.py`、`InlineSpeechTests.swift`。

### 聊天、记忆与提醒

已验证本地模型的多轮称谓/偏好、上下文追问、真实 Core 提醒调用以及结果交回原问题。普通新话题不继承旧敏感历史；明确记忆纠正保留来源，遗忘不从旧摘要自动复活。

提醒真实测试曾发现缺事项被误用时间作标题、以及时区换算偏移。修复后补充信息在原任务内恢复，单条提醒只保存一次，使用正确时区；运行库未为验收创建测试提醒。定时任务与推送送达分别检查。

对应：`test_chat_pipeline_live.py`、`test_reminder_plan_live.py`、`test_reminder_planning.py`、`test_notifications_live.py`。

## 较早集成记录的使用方式

此前已对真实 PostgreSQL/OPA、NATS、SearXNG、Docling、本地模型、部分 ASR/TTS、Mem0/Graphiti、邮件协议及 Home Assistant 做过分项验证。安卓与 iOS 的真机记录涵盖无线、画中画和输入等特定范围。依赖环境已变化时应重新验收，不能把旧记录当作当前服务在线证明。

远程方案经历严格直连和后续可选密文备用通道两个阶段。早期“禁止中继”的说明属于当时配置；当前普通 API 可在明确允许后转发端到端密文，安卓实时媒体仍直连。后续当前网络验收不能替代全部蜂窝跨网场景。

曾有安卓实体熄屏后不能自动恢复亮屏的真机反馈，功能保持默认关闭。系统音频受设备版本和应用限制，不能把模拟器声音成功等同旧版安卓支持。
