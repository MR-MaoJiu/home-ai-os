## 实际环境

- Apple Silicon Mac，Xcode 27.0；iPhone 17 Pro / iOS 27.0 模拟器已安装并启动应用。
- PostgreSQL 17 + pgvector、NATS 2.11、OPA 1.4.2 在 Docker 中实际运行，仅绑定本机端口。
- llama.cpp 8460，官方 Qwen3-0.6B-Q8_0 GGUF；仅为链路验证模型，不作为最终质量承诺。
- `homeai_runtime` 为实际业务库；`homeai_test` 为集成测试库。最初的 `homeai` 保留早期测试数据，没有删除。
- 本机启动地址：API `https://localhost:58443`，模型 `http://127.0.0.1:58080`。

## 测试证据

当前最终测试集实际结果：**20 项通过**（含真实 PostgreSQL/OPA/NATS 与 llama.cpp）。真实 HTTPS 配对 → 签名请求 → worker → 模型回答也已通过，验收设备随后已撤销。

运行记录见 `logs/live-smoke.log`、`logs/full-validation.log`、`logs/integration.log`、`logs/model-integration.log`、`logs/ios-build.log`。单元测试覆盖重放、撤销、跨成员/家庭、共享撤回、版本冲突、墓碑、加密 AAD、审批与幂等、策略不可用、云端拒绝、模型参数边界、记忆确认与备份损坏。

本机恢复演练已生成 `state/backups/development-validation.haib` 并恢复到独立 `homeai_restore_validation_20260917`，未覆盖运行库。此次样本很小且没有真实附件，不能证明大规模恢复性能。

这些测试不能替代外部 Provider、真机、完整威胁模型和生产恢复验收。GitHub Actions 仅已提交配置，未执行远端 CI。
