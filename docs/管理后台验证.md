# 管理后台验证

参考设计：assets/admin-concept.png。实现保留左侧导航、白底、低饱和青色、模型表单、说明侧栏和下方模型表格。

实际验证：

- 1440×1000 桌面布局：导航、表单和表格无裁切。
- 登录使用隔离测试数据库，验证密码＋动态验证码后读取真实接口。
- 模型表格显示测试库实际 Provider，不使用演示数据冒充配置结果。
- 页面包含加载、错误、空状态及成功反馈；敏感操作重新认证入口独立可见。
- 移动布局采用折叠菜单、单列表单和可滚动表格。

与生成图相比，示例模型名称改为实际配置提示，凭据字段不预填掩码假数据，已配置表格使用真实记录；文字不承诺当前尚未完成的云端隐私或生产隔离能力。
