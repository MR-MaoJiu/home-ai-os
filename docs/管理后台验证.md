# 管理后台验证

本文是当前管理后台的手工验证步骤，不是已通过的验收记录。实际执行后，按环境、版本、步骤、结果和失败原因记录到 [验收记录](验收记录.md)；未执行的步骤保留“待验证”。部署入口见 [README](../README.md)。

## 准备与页面范围

- 使用独立测试家庭、测试成员和资料；数据库迁移到当前 `head`。不要用清空业务数据或启用自动备份来准备验证。
- 构建 `admin-web`，通过家庭服务的同源 HTTPS `/admin/` 访问，保留浏览器开发者工具的网络与控制台检查。
- 需要实测的模型、搜索、安卓和 APNs 使用各自真实环境；缺少环境时记录缺项，不填演示结果。
- 分别检查桌面和窄屏：导航可达，表单与表格可操作，长包名、错误文字和二维码不遮挡按钮；加载、空状态、失败和成功反馈能区分。

当前导航为：**概览、模型与凭据、Provider、成员与设备、通知配置、备份与恢复、远程连接、审计**。后台负责配置与运维，不应出现成员聊天、数据、记忆、任务审批或自动化内容列表。这些内容由 iOS 按成员与共享范围展示，任务执行仍在服务端。

## 登录、会话与权限

1. 未登录访问管理接口，应返回未认证；直接打开页面只能进入登录或初始化流程。
2. 从服务器本机按 README 获取五分钟一次性初始化凭据，创建管理账户并绑定 TOTP。没有凭据、凭据过期或再次使用同一凭据时不能初始化；密钥只在本次绑定时展示。
3. 日常使用用户名与动态验证码登录；恢复备用密码不是页面上的日常登录入口。已使用的动态码不能重放，多次错误后显示限流原因。
4. 登录有效期为 **24 小时**。在有效期内刷新、切页和正常管理操作不应每几分钟再次索要动态码；页面一直打开不会让会话无限续期。退出、撤销网页设备、账户恢复或会话到期后，旧会话应失效。
5. 检查会话 Cookie 为 `__Host-`、Secure、HttpOnly、SameSite=Strict、路径 `/` 且没有 Domain；CSRF Cookie 需供前端读取，不应误设 HttpOnly。长期登录令牌不进入 localStorage。
6. 在隔离环境以缺失／错误 CSRF 头、跨源请求访问写接口，应被拒绝；正常同源请求可用。修改资源 ID、成员 ID 或家庭 ID，不能越权管理其他家庭。

## 概览、模型与 Provider

1. “概览”的有效设备数与部署检查读取真实接口；停止测试环境中的相关 Worker 后，应显示未就绪，而不是继续显示可用。
2. “模型与凭据”为空时仍能看到内置目录。部署器未运行时明确提示；启动 `run_builtin_services.py` 后，搜索和所选本地模型经历真实部署与健康检查，失败有原因。不能把容器存活等同于搜索引擎可用。
3. 接入云模型时核对 Base URL、模型、用途和凭据的真实契约；保存后凭据不回显。文本／工具／视觉与图片生成／编辑分别配置，不能把视觉通过当作生图通过。
4. 分别指定本地简答、本地隐私处理、云端规划、视觉理解、图片生成与图片编辑。保存配置不调用模型；使用公开样例验证后应显示各项能力结果、验证时间、实际返回模型及错误类别。配置变更后旧验证失效。
5. 云端超时、模型拒答、输出截断或本地隐私故障时，客户端应展示真实失败或等待状态；不应自动改用更贵模型、绕过隐私检测或虚报工具已执行。HTTP 地址可达、模型列于目录、Provider 已启用，都不能代替真实生成验证。
6. 家庭与成员默认 Token 额度分别验证有限值、`0` 停用和“不限”；图片张数独立。单成员自定义额度在“成员与设备 → 额度设置”中验证继承、覆盖与不限；调整不能清空当天用量或绕过家庭总额，单任务调用／步骤限制继续生效。
7. 使用隔离配置检查 MCP 显式工具映射与 Skill 登记、启用和停用；工具目录变化不能自动扩权。Shell 区域只展示本机策略和环境检查，不提供网页任意登记宿主管理动作的入口。
8. 在 Provider 页停用某能力后，新任务不能再使用；记忆 Provider 停用不能删除规范记忆。健康状态仅表示对应探测或最近调用结果，不能标作所有业务验收完成。

## 成员、配对与安卓执行设备

1. 设置手机可达的家庭 HTTPS 地址，创建测试成员并生成配对二维码。未开通远程时使用局域网入口；已开通远程时验证外网首次扫码。手机无需手输地址，二维码过期或重复使用应明确失败。
2. 页面“我的设备”不应伪装为全家庭设备内容浏览器。撤销测试设备后，其后续请求与连接不能继续访问成员数据。
3. 安卓先由本机登记 ADB 路径与设备身份，再在后台绑定成员。后台展示绑定、实际连接方式及状态，不展示屏幕、账号或成员输入内容；家庭管理员不能借绑定管理取得他人的人工控制权。
4. 用测试成员验证 AI 应用范围：

   | 输入 | 预期 |
   |---|---|
   | 空列表 | 禁止 AI 操作任何 App；本人仍可完整接管 |
   | 单独 `*` | 允许 AI 操作全部 App，仍检查任务权限与动作风险 |
   | 每行具体包名 | AI 启动、观察和执行受实际前台包名限制 |
   | `*` 与包名混填 | 拒绝保存并给出原因 |

5. 在 iOS 中用公开测试页面验证人工接管；AI 不能抢占人工控制，也不能恢复已被接管中断的旧任务。任务结束后释放控制权，其他成员不能操作此设备。
6. 在真实安卓与 iPhone 上分别验证静止画面、动态画面、断网重连和触控恢复；静止无新帧不能等同断线，触控失活应保留只读视频。聊天小窗、全屏与系统画中画应复用同一连接，关闭观看不取消服务端任务。
7. 系统画中画须实际切到其他 App 检查持续播放；分别检查已有视频时的自动尝试和悬浮面板手动开启，未能启动或保持画中画时应暂停观看。Android 10 及更早版本不应显示已获得系统音频，实体熄屏默认关闭，未通过机型恢复验证不能开放。

## 通知配置与备份恢复

1. 在“通知配置”保存测试应用的 Key ID、Team ID、Bundle ID 和 `.p8`。重新加载只显示已配置状态；不选择新文件应保留原密钥。关闭系统推送后站内通知保留，不能因存在环境变量而重新启用。
2. 启动通知 Worker 后检查进程状态。页面“已配置”只证明结构与进程检查；还需分别记录 Apple 接受、真机实际收到、点击进入正确内容且不崩溃。自编译者使用自己的签名与 APNs，不能把官方应用私钥分发给家庭服务器。
3. “备份与恢复”默认关闭。仅访问页面或保存目录不得创建备份；目录指家庭服务器上的绝对路径。定时频率需显式启用，选择“仅手动”应关闭定时。
4. 修改未保存时不能“立即备份”；保存后提交一次任务，观察排队、运行、成功／失败及真实归档。Worker 未运行或路径不可用时，不能把请求已提交显示成完成。
5. 关闭自动备份不删除已有归档。恢复在本机隔离目标执行，使用独立保管的备份密钥、数据主密钥、最新删除日志和记忆遗忘日志；重放后确认旧数据不会复活，再开放访问。网页不应提供直接覆盖运行数据库的按钮。

## 远程连接与审计

1. 默认平台地址为 `https://homeai-connect.pintheworld.cn`；可填写兼容协议的第三方协调平台。获取真实开放套餐与客服联系方式；无套餐或无客服时不能生成可开通申请。
2. 生成申请码并由客服开通，家庭端自动领取绑定配置。开通后使用平台下发的 STUN，不需要另选配置来源；自定义项当前最多两个地址，留空保存恢复平台配置，已有设备按页面提示重新扫码更新。
3. 平台协商在线不等同 P2P 已连通。使用蜂窝 iPhone 与另一网络家庭端完成真实业务请求，并检查连接两端；关闭备用通道时无法直连应明确失败；明确允许后验证普通 API 可经端到端密文备用通道，不可暗中启用 TURN 或 frp。安卓实时媒体仍单独验收。
4. 停用远程后验证本地服务继续工作；恢复远程后重新鉴权。STUN 公网可达、平台在线和应用请求成功分别记录。
5. “审计”只展示有权查看的操作记录与云端披露元数据。确认记录关联实际调用，未发送不能记作披露成功；不得展示密钥、TOTP、私人聊天、屏幕原图或未经授权的资料正文。

验证输出只记录必要的版本、状态、错误类别和脱敏证据；不要把 Cookie、二维码、成员私人内容、设备序号或真实服务凭据提交到仓库。

## 客户端与服务端联合回归

- 持续会话：关闭页面、断网重连与资料同步后，消息仍属于同一成员会话；连续触发会话重验时不先清空整页。撤权后的正文仍必须隐藏。
- 聊天与任务：普通聊天可流式输出，任务接话不宣称已完成，结果回到原任务；等待客户端期间可以继续其他聊天。
- 自动审核：默认关闭，开启必须确认风险并出现橙色提示；仅当前设备本人任务自动批准，其他成员和系统权限不被代办。断线不能假装关闭成功，关闭确认后新请求恢复手动，已处理请求不可重放。
- 健康：先提供睡眠，再请求包含心率的报告，应复用睡眠并只补缺项；无样本、指标子集、范围漂移、分块、版本变化和明确重采分别验证。
- 朗读：接话、结果、等待/失败文字和历史都有手动入口；新消息按设置自动读，历史不重播；资料刷新后重验，失效内容不能从音频缓存继续播放。
- 提醒：给出时间但缺事项时仅补事项，原任务继续；检查时区、一次创建、到期通知和重启去重。

这些步骤是验收要求，是否通过以当前实际记录为准。不要为执行此清单开启真实成员的自动审核或自动备份。
